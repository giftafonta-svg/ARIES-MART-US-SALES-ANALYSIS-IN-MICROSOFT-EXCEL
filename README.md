# ARIES-MART-US-SALES-ANALYSIS-IN-MICROSOFT-EXCEL
Excel analysis of ~10K US retail transactions (2014–2017) sourced from Kaggle. Built pivot tables and a dashboard covering sales by sub-category, monthly sales trends, top 5 customers by profit, sales by state, and unique customer counts. Demonstrates PivotTables, aggregation formulas, and dashboard design in Excel.
